# 短時間勤務者採用プロジェクト

会社の原価改善施策として位置付ける重点プロジェクト。短時間勤務者を採用し、
ピーク時間帯の人員を最適化することで人件費原価の改善を図る。

## 成果物

- **`採用プロジェクト_資料.pptx`** — プロジェクト説明用のパワーポイント資料（全9スライド）

### スライド構成

| # | スライド | 内容 |
|---|----------|------|
| 1 | 表紙 | プロジェクト名・目的・対象拠点・採用目標 |
| 2 | 目的 | 人件費原価の改善／ピーク人員の最適化／重点プロジェクト化 |
| 3 | 採用目標 | 成田10名・新千歳10名・合計20名 |
| 4 | プロジェクト体制 | 統括：遠藤／PMリーダー：内山／実務：野澤／制度・労務：髙田部長／現場調整窓口：坂本 |
| 5 | 募集媒体・掲載期間 | 空港・媒体別の掲載スケジュール（バイトル／マイナビバイト） |
| 6 | 担当業務 | メンバー別の主な担当業務（坂本＝入社後フォロー・トラブル対応・現場調整窓口） |
| 7 | 面接体制 | 人事2名＋現場管理職1名の面接構成 |
| 8 | 進捗管理項目（KPI） | 採用ファネル＋媒体別・空港別の集計 |
| 9 | 基本方針 | 役割分担と連携方針 |

## 資料の再生成

```bash
npm install                    # 初回のみ（pptxgenjs を導入）
npm run build                  # = node scripts/build_pptx.js。採用プロジェクト_資料.pptx を出力
```
